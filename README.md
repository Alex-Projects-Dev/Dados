# Cinco Dados

Juego de dados en el navegador para 1 a 5 jugadores. Abre `index.html` para jugar.

## Reglas
- Cada turno tiras 5 dados hasta 3 veces. Toca un dado para guardarlo entre tiradas.
- **Unos a Seises:** suma de los dados con ese número.
- **Escalera corta:** 4 números seguidos = 30 puntos.
- **Escalera larga:** 5 números seguidos = 40 puntos.
- **Full:** 3 dados iguales y otros 2 iguales = 25 puntos.
- **Libre:** suma de los 5 dados.
- El juego calcula lo que vale cada casilla con tus dados y marca la mejor opción. Tú eliges dónde anotar.
- Cada casilla se usa una vez; tras 10 rondas gana quien tenga más puntos.
